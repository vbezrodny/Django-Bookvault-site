# BioVault: описание проекта для нового разработчика

## Что это за сайт

**BioVault** - это Django-сайт интернет-магазина товаров для биохакинга, здоровья и wellness-направления.

С точки зрения пользователя сайт выглядит как витрина, где можно посмотреть категории, выбрать товары, добавить их в корзину, оформить заказ, открыть личный кабинет и прочитать справочную информацию.

Основная тематика:

- умные браслеты и трекеры здоровья;
- БАДы и нутрицевтики;
- сон и восстановление;
- диагностика и домашние тесты;
- фокус, энергия и стресс;
- гидратация, иммунитет и долголетие;
- персональные наборы для здоровья.

Проект исторически назывался **BookVault**, поэтому в коде еще встречаются технические имена `books`, `Book`, `book-card` и похожие названия. Сейчас это не книжный магазин: эти названия остались как часть внутренней структуры и используются для каталога товаров.

## Общая архитектура

Проект состоит из трех крупных частей:

- **Django backend** - маршруты, страницы, аккаунты, админка, API и база данных.
- **Vue frontend** - интерактивность на страницах: корзина, фильтры, табы, формы, профиль, заказы.
- **Static files** - CSS, JavaScript, изображения, шрифты и иконки.

Главная точка входа проекта - файл `manage.py` в корне. Через него запускают сервер, миграции и проверки Django.

Основная конфигурация проекта находится в папке `bookvault`.

## Структура папок

```text
Django-Bookvault-site/
├── accounts/        # регистрация, вход и пользовательские аккаунты
├── books/           # каталог товаров и категорий, API каталога
├── bookvault/       # настройки Django-проекта и главные URL
├── static/          # CSS, JS, изображения, шрифты
├── store/           # публичные страницы сайта
├── db.sqlite3       # локальная SQLite-база данных
├── manage.py        # CLI-точка входа Django
├── requirements.txt # Python-зависимости
├── package.json     # frontend-зависимости
└── README.md        # старое проектное описание
```

## Django-приложения

### `bookvault`

Папка `bookvault` содержит настройки всего Django-проекта.

Самые важные файлы:

- `settings.py` - настройки приложений, базы данных, статики, медиа и Django.
- `urls.py` - главный список маршрутов проекта.
- `asgi.py` и `wsgi.py` - стандартные точки входа для запуска приложения на сервере.

Главные маршруты подключаются так:

```text
/admin/     -> административная панель Django
/           -> публичные страницы сайта
/accounts/  -> вход, регистрация и аккаунты
/api/       -> API каталога
```

### `accounts`

Приложение `accounts` отвечает за пользовательские аккаунты.

Здесь находится логика:

- регистрации;
- входа;
- выхода;
- страниц авторизации.

Пользовательские формы входа и регистрации визуально оформлены под BioVault. Они не меняют структуру проекта, а только позволяют пользователю авторизоваться в системе.

### `books`

Приложение `books` сейчас фактически отвечает за **каталог товаров BioVault**.

Название осталось историческим, но содержательно здесь хранятся:

- категории биохакинга;
- товары;
- API для выдачи категорий и товаров на frontend.

Основные файлы:

- `models.py` - модели данных.
- `serializers.py` - преобразование данных в JSON.
- `views.py` - API-представления.
- `urls.py` - API-маршруты.
- `admin.py` - регистрация моделей в Django-admin.

В `models.py` есть две главные сущности:

| Модель | Что означает сейчас |
|---|---|
| `Category` | Категория товаров: браслеты, БАДы, сон, диагностика и т.д. |
| `Book` | Товар каталога: браслет, сенсор, БАД, набор или wellness-решение |

У товара есть:

- название;
- краткое описание или тип товара;
- цена;
- рейтинг;
- количество отзывов;
- категория;
- признак новинки;
- изображение.

API доступно по адресам:

```text
/api/books/       # список товаров
/api/categories/  # список категорий
```

### `store`

Приложение `store` отвечает за публичную часть сайта.

Пользовательские разделы:

- главная страница;
- каталог;
- категории;
- карточка товара;
- оформление заказа;
- профиль;
- контакты и помощь;
- страница о компании.

Именно здесь задается, какие страницы доступны пользователю и по каким URL они открываются.

## Что видит пользователь

Главная страница представляет BioVault как магазин решений для биохакинга.

На ней есть:

- отзывы клиентов;
- призыв перейти к подбору товаров.

Раздел категорий помогает пользователю быстро выбрать направление.

Примеры категорий:

- гидратация;

- долголетие.

На странице есть поиск и вкладки:

- популярные;

- новые;

### Карточка товара

Карточка товара показывает подробную информацию о продукте.

Сейчас основная демо-карточка оформлена вокруг **WHOOP 4.0 Health Band**.

На странице есть:

- название товара;

## Frontend-логика

Главный frontend-файл:

```text
static/js/app.js
```

Он создает Vue-приложение, подключает модули и передает данные на страницы.

Frontend-модули находятся здесь:

```text
static/js/modules/
```

Основные модули:

| Файл | За что отвечает |
|---|---|
| `auth.js` | модальное окно авторизации и состояние входа |
| `cart.js` | корзина, добавление и удаление товаров, сумма заказа |
| `index_page.js` | товары и отзывы на главной странице |
| `catalog.js` | загрузка каталога из API, фильтры, сортировка, пагинация |
| `categories.js` | поиск и вкладки категорий |
| `about.js` | статистика и команда |
| `checkout.js` | оформление заказа, оплата, промокоды, итоговая сумма |
| `contact.js` | раскрывающиеся вопросы в FAQ |
| `profile.js` | профиль, наборы, желания и заказы |
| `product.js` | карточка товара, количество, вкладки, галерея |

Vue используется точечно: страницы уже отдаются Django, а Vue оживляет отдельные интерактивные части.

## Стили и изображения

Статические ресурсы лежат в папке `static`.

```text
static/
├── css/      # стили сайта
├── js/       # Vue и модули frontend-логики
├── images/   # локальные изображения
├── fonts/    # шрифты
└── webfonts/ # иконочные шрифты Font Awesome
```

Проект использует Tailwind CSS.

Главные CSS-файлы:

- `static/css/tailwind.css` - входной Tailwind-файл;
- `static/css/tailwind-output.css` - собранный CSS;
- `static/css/style.css` - общие стили;
- отдельные CSS-файлы для страниц: `catalog.css`, `about.css`, `checkout.css`, `contact.css`, `profile.css` и другие.

Локальные изображения из проекта не удалялись. Для новой тематики BioVault в контент добавлены внешние изображения, в основном через URL.

## База данных

Проект использует SQLite:

```text
db.sqlite3
```

В базе лежат:

- стандартные таблицы Django;
- пользователи;
- категории;
- товары каталога.

Категории и товары уже переписаны под BioVault.

Примеры товаров:

- WHOOP 4.0 Health Band;
- Magnesium Sleep Complex;
- Omega-3 Ultra;
- Sleep Recovery Kit;
- Glucose Insight Sensor;
- Vitamin D3 + K2;
- Focus Adaptogen Blend;
- HRV Breathing Trainer;
- Smart Hydration Bottle.

Важно: таблицы и модели могут называться `books`, но по смыслу это каталог товаров.

## API каталога

Frontend получает данные каталога через API.

```text
GET /api/books/
GET /api/categories/
```

Товар отдается в формате JSON и содержит поля, удобные для Vue:

- `id`;
- `title`;
- `author`;
- `price`;
- `rating`;
- `reviews`;
- `categoryId`;
- `isNew`;
- `image`.

Поле `author` сейчас используется как короткое описание или тип товара. Например: `Трекер восстановления`, `Нутрицевтик для сна`, `Мониторинг метаболизма`.

## Как менять наполнение

### Изменить товары каталога

Товары лежат в базе `db.sqlite3`.

Их можно менять:

- через Django-admin;
- через shell Django;
- через отдельный Python-скрипт, который обновляет SQLite.

### Изменить категории

Категории тоже лежат в базе.

Если нужно поменять только демонстрационные категории на некоторых страницах, дополнительно проверьте:

```text
static/js/app.js
```

### Изменить главную страницу

Рекомендуемые товары и отзывы находятся здесь:

```text
static/js/modules/index_page.js
```

### Изменить профиль, наборы и заказы

Демо-данные личного кабинета находятся здесь:

```text
static/js/modules/profile.js
```

### Изменить оформление заказа

Демо-корзина, промокоды и способы оплаты находятся здесь:

```text
static/js/modules/checkout.js
```

### Изменить внешний вид

Сначала стоит смотреть:

```text
static/css/
```

Часть внешнего вида задана Tailwind-классами прямо в HTML-разметке страниц.

## Что важно не перепутать

- `books` в коде не означает, что сайт все еще про книги. Это историческое название приложения каталога.
- `Book` в модели сейчас играет роль товара.
- `author` у товара используется как короткое описание или тип товара.
- `book-card` в CSS - технический класс карточки товара.
- Пользовательская тематика сайта уже BioVault: биохакинг, здоровье, БАДы, браслеты, диагностика и восстановление.

## Как запустить проект

Установить Python-зависимости:

```bash
pip install -r requirements.txt
```

Запустить Django-сервер:

```bash
python manage.py runserver
```

Если нужно пересобрать Tailwind CSS:

```bash
npx tailwindcss -i ./static/css/tailwind.css -o ./static/css/tailwind-output.css --watch
```

После запуска сайт обычно доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Короткое резюме

BioVault - это Django + Vue интернет-магазин товаров для биохакинга.

Django отвечает за страницы, маршруты, API, аккаунты и базу данных. Vue отвечает за интерактивность: каталог, фильтры, корзину, профиль, оформление заказа и вкладки. SQLite хранит товары и категории. Статика лежит в `static`, публичные страницы - в `store`, аккаунты - в `accounts`, каталог и API - в `books`.

Новому разработчику стоит начать изучение проекта с файлов:

```text
bookvault/urls.py
bookvault/settings.py
store/urls.py
books/models.py
books/serializers.py
static/js/app.js
static/js/modules/catalog.js
static/js/modules/cart.js
```
